PROJETO 02

Oversteer.

Uma plataforma web de automobilismo para acompanhar corridas, resultados, notícias e dados ao vivo.

ÁreaProduto web
TecnologiasFastAPI · PostgreSQL
StatusProjeto privado

A proposta

Reunir informações de diferentes séries do automobilismo em uma experiência única, com conteúdo personalizado para cada pessoa.

O que foi construído

  • API com autenticação, favoritos e perfis de usuário.
  • Calendário de eventos, sessões, resultados e classificações.
  • Ingestão de notícias via RSS e dados de corridas.
  • Atualizações ao vivo usando Redis e SSE.
  • Observabilidade, métricas, health checks e pipeline de testes.
